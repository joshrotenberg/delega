# delega-mcp

Expose the delega supervisor over the Model Context Protocol. The server
provides tools to start, inspect, wait for, interrupt and close sessions.
It also exposes delega's bundled skills as resources.

The [delega CLI](https://github.com/joshrotenberg/delega) runs this server
over stdio with `delega mcp`. See the
[delega documentation](https://joshrotenberg.com/delega/) for setup and the
tool contract.
